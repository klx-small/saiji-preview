# 赛迹 Saiji · 公开交互演示

校园竞赛信息、资料共享、经验交流与团队协作平台的静态产品体验版。

本仓库仅保存经过检查的 HTML、CSS、JavaScript、字体、图片、发布清单及 GitHub Pages 工作流。完整源码和生产版本在独立的私有仓库中维护。本仓库不包含 Express 服务、数据库、生产环境配置、密钥或用户附件。

## 如何体验

打开本仓库 GitHub Pages 部署成功后显示的网站地址，点击「进入演示」。演示无需注册、密码或邮箱。登录入口沿用赛迹的暗色设计，内部工作台支持日间和夜间模式。

可体验赛事搜索与筛选、内容详情、模拟资料下载、收藏、队伍申请与撤回、模板队伍创建、训练赛报名与分组、模板投稿及本地审核。全部赛事、人物、团队、成绩和投稿均为虚构 Demo 示例。

## 数据与安全边界

- 页面不连接生产 API，不发送邮件，不创建真实账号，不授予管理员权限。
- 演示状态保存在当前浏览器的版本化本地存储中。刷新和退出演示后保留；不同设备、浏览器和访客之间不共享。
- 「重置演示数据」在确认后恢复初始示例。清理浏览器站点数据同样会删除本地体验状态。
- 投稿和创建流程使用固定虚构模板，不接收真实密码、联系方式、个人隐私或附件。
- 模拟下载为本地生成的 Demo 文本，不是原始参赛材料。
- 管理员界面只演示当前浏览器内的内容状态，不是真实后台。

## 发布方式

本仓库由私有项目的独立预览构建生成，构建资源路径固定为 /saiji-preview/，使用 HashRouter 支持静态页面刷新。main 分支的已审查静态文件由官方 GitHub Pages Actions 发布。工作流不会创建仓库、修改仓库可见性或绑定自定义域名。

release-manifest.json 记录本次静态文件的 SHA-256，用于下次发布前核对受管理文件，防止覆盖未知内容。仓库地址可见不等于网站已经部署成功；实际部署状态以 Actions 和 Pages 环境记录为准。
